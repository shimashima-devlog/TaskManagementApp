# 作成予定機能

## アプリ概要
タスクの登録・一覧表示・編集・削除を行うためのWEBアプリケーションを作成する。
タスクごとに担当者、期限、ステータス、備考を管理できるようにする。

## 作成予定機能

### タスクの一覧表示
- 登録されているタスクを一覧で表示する。
- タスク名、担当者、期限、ステータス、備考を確認できるようにする。

### タスクの新規登録
- 新しいタスクを登録できるようにする。
- タスク名、担当者、期限、ステータス、備考を入力できるようにする。

### タスク内容の編集
- 登録済みのタスクを編集できるようにする。
- タスク名、担当者、期限、ステータス、備考を変更できるようにする。

### タスクの削除
- 登録済みのタスクを削除できるようにする。
- 誤操作を防ぐため、削除前に対象のタスクを確認できるようにする。

### 入力チェック
- タスク名、担当者、期限を必須入力とする。
- ステータスは選択式とし、「未着手・対応中・完了」から選択する。
- 備考は任意入力とする。
- 必須項目が未入力の場合は、エラーメッセージを表示する。

### データの保存・読み込み
- 登録したタスクをデータベースに保存する。
- 保存したタスクをデータベースから読み込み、一覧画面に表示する。
- データベースには、SQLiteを使用する。
