# 簡易設計資料

## 1. アプリケーション概要
- タスクの一覧表示、新規登録、編集、削除を行うためのWebアプリケーション。
- タスクのデータはSQLiteに保存する。

---

## 2. 機能一覧
- タスクの一覧表示
  - 登録されているタスクを一覧で表示する。

- タスクの新規登録
  - タスク名、担当者、期限、ステータス、備考を入力して登録する。

- タスクの編集
  - 登録済みのタスク内容を変更する。

- タスクの削除
  - 登録済みのタスクを削除する。

- 入力チェック
  - 必須項目が未入力の場合はエラーメッセージを表示し、登録・更新を行わず、画面を再表示する。

- データ保存・読み込み
  - SQLiteにタスクデータを保存し、一覧表示時に読み込む。

---

## 3. 管理するデータ
- ID
  - タスクを識別するためのID。

- タスク名
  - タスクの名称。
  - 必須の入力項目。

- 担当者
  - タスクの担当者。
  - 必須の入力項目。

- 期限
  - タスクの期限。
  - 必須の選択項目。

- ステータス
  - タスクの進捗状況。
  - 「未着手」「対応中」「完了」から選択。
  - 必須の選択項目。

- 備考
  - タスクに関する補足情報。
  - 任意の入力項目。

---

## 4. 画面構成
- タスク一覧画面から、新規登録・編集・削除の各画面へ遷移できる。

```text
タスク一覧画面
├─ 新規登録
│  └─ 新規登録画面
│     └─ 登録 → タスク一覧画面
├─ 編集
│  └─ 編集画面
│     └─ 更新 → タスク一覧画面
└─ 削除
   └─ 削除確認画面
      └─ 削除 → タスク一覧画面
```

### タスク一覧画面
- 登録されているタスクを一覧表示する。
- 新規登録、編集、削除画面へ遷移できる。

### 新規登録画面
- タスク情報を入力し、新しいタスクを登録できる。

### 編集画面
- 登録済みのタスク情報を表示し、登録内容を変更できる。

### 削除確認画面
- 削除対象のタスクを表示し、削除を実行する。

---

## 5. 処理概要

### 一覧表示
ユーザーがタスク一覧画面にアクセスする。  
→ Controllerがデータベースからタスクデータを取得する。  
→ 取得したデータをViewに渡す。  
→ タスク一覧画面に全タスクが表示される。

### 新規登録
ユーザーが新規登録画面でタスク情報を入力する。  
→ ユーザーが[登録]ボタンを押す。  
→ 入力内容がControllerに送信される。  
→ Controllerが入力チェックを行う。  
→ 問題がなければ、SQLiteにデータを保存する。  
→ タスク一覧画面へ遷移する。  
→ 登録したタスクが一覧に表示される。

### 編集
ユーザーがタスク一覧画面から編集対象のタスクを選択する。  
→ ControllerがIDをもとに対象のタスクデータを取得する。  
→ 編集画面に変更対象のタスクデータを表示する。  
→ ユーザーがタスクデータの内容を変更する。  
→ ユーザーが[更新]ボタンを押す。  
→ 入力内容がControllerに送信される。  
→ Controllerが入力チェックを行う。  
→ 問題がなければ、SQLiteのデータを更新する。  
→ タスク一覧画面へ遷移する。  
→ 更新した内容がタスク一覧に表示される。

### 削除
ユーザーがタスク一覧画面から削除対象のタスクを選択する。  
→ ControllerがIDをもとに対象のタスクデータを取得する。  
→ 削除確認画面に対象のタスクデータを表示する。  
→ ユーザーが[削除]ボタンを押す。  
→ Controllerが削除処理を行う。  
→ SQLiteから対象のデータが削除される。  
→ タスク一覧画面へ遷移する。  
→ 削除したタスクがタスク一覧画面に表示されなくなる。
